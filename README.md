## 📚 Detailed Usage Guide

### 🎯 Selecting Items

Once the viewer is running, each entry shows a short name like `Reimu`, `Flandre`, or `MountainOfFaith`. Type a partial name and press Tab to auto-complete. Press Enter to display.

### ⏩ Speed Control for Animations

Some danmaku and scene animations play at a fast speed. If you want slow motion, press `-` (minus key) to reduce speed. Press `=` (equals key) to increase speed. Press `0` to reset to default.

### 🎨 Colors and Style

By default, the viewer uses ANSI colors. If colors look wrong or are missing:
- Press `C` to toggle color mode.
- Press `M` to switch between monochrome and colorful character sets.
- Press `U` to use Unicode art (requires Windows 10 or newer).

### 💾 Saving Art to a File

To copy any artwork as plain text:
1. Display the art you like.
2. Right-click the terminal title bar, choose **Edit**, then **Select All**.
3. Press **Ctrl + C** to copy.
4. Paste into Notepad or any Word document.

### 🖼️ Setting as Terminal Background

For Windows Terminal users, you can set any ASCII scene as wallpaper. Open Windows Terminal Settings, go to **Appearance**, find **Background image path**, and select the `.txt` file you want. Set opacity to 50% for the best look.

## 🛠️ Troubleshooting Tips

### ⚠️ "viewer is not recognized"

This means your terminal is in the wrong folder. Double-check the path you typed with `cd`. You can type `dir` in the terminal to see a list of files. If you see `viewer.exe` in the list, you are in the right place.

### 🚫 Blank screen or weird symbols

Your terminal font may not support special characters. Go to terminal settings and change the font to `Cascadia Mono`, `Consolas`, or `Lucida Console`. These always work.

### 🐢 Animations lagging

Older computers might struggle with fast animations. Press `-` several times to slow down. Also close other heavy programs (browsers, games) for smoother playback.

### ❓ Nothing shows after pressing Enter

Some artworks are extremely wide and require a larger terminal window. Click and drag the edges of your terminal window to make it bigger, or maximize it. Then press the key again.

### 🔧 Resetting Everything

If you ever mess up settings, simply close the terminal window and reopen it. The viewer has no persistent memory; every session starts fresh.
